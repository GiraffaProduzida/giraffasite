# /public/images

Pasta reservada para as fotos reais do site (hoje vazia — o protótipo
usa placeholders coloridos, ver `src/components/ui/PlaceholderImage.tsx`).

- `artistas/` — fotos de artistas, nomeadas pelo `slug` do artista
  (ex: `luna-cerrado.jpg` para o artista de slug `luna-cerrado`).
- `loja/` — fotos de produtos, nomeadas pelo `slug` do produto.

Ver `docs/CONTENT_GUIDE.md` para o passo a passo de como trocar os
placeholders por estas fotos.
